# DraftRecorder

Records audio notes and transcriptions, syncing them across devices for personal use and small team collaboration.

DraftRecorder is aimed at developers who need a straightforward, dependable solution.

- python

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/DraftRecorder.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

DraftRecorder is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
